Números de WhatsApp (bots)

El código se asigna solo (B1, B2, B3…). Un número nuevo entra en CALENTAMIENTO. El estado cambia solo: pasa a ACTIVO cuando su fan page vinculada tiene anuncios activos en Meta y a SIN USO cuando esas campañas se apagan. Meta no entrega el número de WhatsApp de cada anuncio (solo la fan page que lo publica), así que el vínculo número ↔ fan page lo indicas tú una vez con «Editar»; desde ahí el estado, la página donde se pauta, las campañas y las conversaciones de hoy se actualizan solos.
